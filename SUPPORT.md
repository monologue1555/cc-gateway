# Support / 获取帮助

Before opening an issue, read the [README](README.md), retry the built-in upstream test, and copy only redacted diagnostic metadata. Never post an API key or a complete configuration file containing credentials.

提交 Issue 前，请先阅读 [README](README_ZH.md)、重试内置上游测试，并且只复制脱敏后的诊断元数据。不要公开 API Key，也不要粘贴包含凭据的完整配置文件。

- Bugs and questions: [GitHub Issues](https://github.com/monologue1555/cc-gateway/issues)
- Security vulnerabilities: [private security report](https://github.com/monologue1555/cc-gateway/security/advisories/new)
- Releases: [GitHub Releases](https://github.com/monologue1555/cc-gateway/releases)

When reporting a gateway problem, include CC Gateway version, operating system, client type, protocol, requested model, HTTP status, and the redacted request ID/end reason shown in diagnostics.

报告网关问题时，请附上 CC Gateway 版本、操作系统、客户端类型、协议、请求模型、HTTP 状态，以及诊断中显示的脱敏 request ID 和结束原因。
